## Descripción del caso

El proyecto consiste en diseñar el modelo fisico de una base de datos para una red social estudiantil.

La plataforma busca facilitar la comunicación y la interacción entre estudiantes mediante perfiles, publicaciones, comentarios, conexiones, grupos, eventos y mensajes.

## Objetivo

Diseñar un Modelo fisico en MySQL donde implementemos todo lo aprendido en el modelo conceptual que realizamos anteriormente

## Entidades principales

- ESTUDIANTE
- INTERESES
- PUBLICACIÓN
- COMENTARIO
- GRUPO
- MIEMBRO_GRUPO
- EVENTO
- ASISTENCIA_EVENTO
- MENSAJE
entre otras.
## Relaciones principales

- ESTUDIANTE CREA PUBLICACIÓN.
- ESTUDIANTE REALIZA COMENTARIO.
- PUBLICACIÓN RECIBE COMENTARIO.
- ESTUDIANTE REGISTRA MIEMBRO_GRUPO.
- GRUPO TIENE MIEMBRO_GRUPO.
- ESTUDIANTE PARTICIPA EN EVENTO.
- ESTUDIANTE REGISTRA ASISTENCIA_EVENTO.
- EVENTO TIENE ASISTENCIA_EVENTO.
- ESTUDIANTE ENVÍA MENSAJE.
- ESTUDIANTE RECIBE MENSAJE.
- ESTUDIANTE SE CONECTA CON ESTUDIANTE.
